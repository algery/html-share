# HTML Share 风险目录

| 编号                      | 等级   | 判定                                              | 对用户的说明                                               |
| ------------------------- | ------ | ------------------------------------------------- | ---------------------------------------------------------- |
| `TARGET_INVALID`          | 阻断   | 目标不是发布目录内的 `.html` / `.htm` 普通文件    | 请明确要分享的 HTML 文件。                                 |
| `PATH_ESCAPE`             | 阻断   | 路径无法规范化或符号链接指向目录外                | 发布包不能读取目录外文件。                                 |
| `SENSITIVE_FILE`          | 阻断   | 发现 `.env`、Git 元数据、私钥、证书或凭证命名文件 | 请将敏感文件移出发布目录后重试。                           |
| `SECRET_CONTENT`          | 阻断   | 文件内容匹配高置信密钥模式                        | 请撤销密钥并移出发布目录后重试。                           |
| `FILE_LIMIT`              | 阻断   | 文件数超过 500                                    | 请缩减发布目录。                                           |
| `FILE_SIZE_LIMIT`         | 阻断   | 任一文件超过 5 MiB                                | 请压缩或移除大文件。                                       |
| `TOTAL_SIZE_LIMIT`        | 阻断   | 文件总大小超过 20 MiB                             | 请缩减发布目录。                                           |
| `ROOT_ABSOLUTE_PATH`      | 需确认 | HTML/CSS 使用以 `/` 开头的资源路径                | 部署后会从 Demo 域根路径请求，资源可能找不到。             |
| `MISSING_LOCAL_REFERENCE` | 需确认 | 本地 HTML/CSS 引用不存在                          | 页面可能出现缺图、无样式或脚本失效。                       |
| `DYNAMIC_PATH`            | 需确认 | 动态导入或动态资源路径无法静态确认                | 页面运行时可能找不到资源。                                 |
| `EXTERNAL_NETWORK`        | 需确认 | 引用 CDN、外部图片、字体或 API                    | 这些请求会离开组织内网络边界，且第三方可用性不受平台保证。 |
